## ഈ ലിഖിതത്തെക്കുറിച്ച്

ഈ ചെറിയ ചുണ്ണാമ്പുകല്ല് ഖണ്ഡത്തിൽ ഏഴ് അപൂർണവരികൾ ശേഷിക്കുന്നു. പഴയ കാണ്ഡഹാറിൽനിന്ന് ലഭിച്ചതായി റിപ്പോർട്ടു ചെയ്യപ്പെടുകയും ആന്ദ്രേ ദുപോം-സോമർ 1966-ൽ പ്രസിദ്ധീകരിക്കുകയും ചെയ്തു. അരമായ അക്ഷരങ്ങളിൽ എഴുതിയ മധ്യഭാരതീയ വാക്യഭാഗങ്ങളും അരമായ വിശദീകരണങ്ങളും പാഠത്തിൽ കലർന്നിരിക്കുന്നു. പ്രധാന സ്തംഭശാസനം 7-ലെ ഒരു ഭാഗവുമായി ഇന്ത്യൻ വാക്യഭാഗങ്ങളെ എമീൽ ബെൻവെനിസ്ത് തിരിച്ചറിഞ്ഞു. ഓരോ വരിയുടെയും തുടക്കം പൊട്ടിയതും ചില വാക്കുകൾ അവ്യക്തവുമായതിനാൽ മൂലവിളംബരത്തിന്റെ സമ്പൂർണമായ തുടർച്ചാവിവർത്തനം സാധ്യമല്ല. ഈ പേജ് **ശേഷിച്ച എല്ലാ വരികളും** നൽകുകയും വ്യാഖ്യാനിക്കാവുന്നതും അല്ലാത്തതും അടയാളപ്പെടുത്തുകയും ചെയ്യുന്നു; പൂർണസ്തംഭപാഠം ശാസനം 7-ന്റെ വേറെ ലേഖനത്തിലുണ്ട്.

താഴെയുള്ള അരമായ അക്ഷരരൂപം ദുപോം-സോമറിന്റെ റോമൻ ലിപ്യന്തരത്തിൽനിന്ന് ക്രമപ്പെടുത്തിയതാണ്. ഇത് മൂലത്തിലെ അക്ഷരങ്ങൾ അതേപടി പകർത്തുന്ന പ്രതിരൂപമല്ല. കുത്തുകൾ പൊട്ടിയതും വായിക്കാനാവാത്തതുമായ കൂട്ടങ്ങളെ സൂചിപ്പിക്കുന്നു; ശേഷിച്ച ചില അക്ഷരങ്ങളും ഉറപ്പില്ലാത്തവയാണ്.

## റോമൻ ലിപ്യന്തരണം

ദുപോം-സോമറിന്റെ പതിപ്പിൽ ശേഷിച്ച ഏഴുവരികൾ ഇവിടെ നിലനിർത്തിയിരിക്കുന്നു. തുടക്കത്തെയും അവസാനത്തെയും വിള്ളലുകൾ കല്ലിൽനിന്ന് പൂരിപ്പിക്കാനാവില്ല.

## മലയാളം വിവർത്തനം

നഷ്ടപ്പെട്ട ഭാഗങ്ങൾ പൂരിപ്പിക്കാതെ തിരിച്ചറിയാവുന്ന വാക്കുകളും വാക്യഭാഗങ്ങളുമാണ് താഴെ വിവർത്തനം ചെയ്യുന്നത്. ചില വായനകളും അർത്ഥങ്ങളും തർക്കവിഷയമാണ്.

> 1. … ‘അനുസരിച്ച്’ …
> 2. … ‘കൂടാതെ, ഏത്’ … [സ്തംഭശാസനം 7-ലെ ‘ഏതു കാര്യങ്ങളായാലും’ എന്നതിനു സമാനമായ ഇന്ത്യൻ വാക്യഭാഗം] …
> 3. … ‘അനുസരിച്ച്’ … ‘ഭൂമി’ … ‘ഇപ്പോൾ’ … [ഉചിതമായ പിന്തുടരലോ പെരുമാറ്റമോ സംബന്ധിച്ച ഇന്ത്യൻ വാക്യഭാഗം] …
> 4. … ‘കൂടാതെ, അനുസരണത്തിൽ അവർ വളർന്നു, ഇനിയും വളരും’ …
> 5. … ‘അനുസരിച്ച് … അനുസരണം’ … [അവസാനവാക്ക് ഉറപ്പില്ല] …
> 6. … [*anuppatipatiyā*, ‘അനുസരിച്ച്’ അഥവാ ‘പിന്തുടർന്ന്’ എന്നതിനു സമാനമായ ഇന്ത്യൻ വാക്യഭാഗം] …
> 7. … [ഉറപ്പില്ലാത്ത വാക്ക്] … ‘ദാസർ’ [അല്ലെങ്കിൽ മറ്റൊരു വായന] …

രണ്ട്, മൂന്ന്, ആറ് വരികളിലെ ഇന്ത്യൻ വാക്യഭാഗങ്ങളെ പ്രധാന സ്തംഭശാസനം 7-ലെ വാക്കുകളുമായി ബെൻവെനിസ്ത് തിരിച്ചറിഞ്ഞു; മാർഗദർശിയിൽ അതിന് പ്രത്യേകം ലേഖനമുണ്ട്. ഈ തിരിച്ചറിയൽ പശ്ചാത്തലം നൽകുന്നു; എന്നാൽ ഈ ഖണ്ഡത്തിലെ നഷ്ടപ്പെട്ട ഭാഗങ്ങളെ പുനഃസ്ഥാപിക്കുന്നില്ല.
